# Prism Nine — development prompt package

This folder contains prompt documentation for another coding AI. It does not create another game implementation or change the current game's source.

## Understanding

You want a polished, colourful block puzzle with a dark neon interface, tactile blocks, precise placement, satisfying line clears, readable scoring, and a complete local playable loop. The coding AI must deliver and verify a working game, rather than stop at a plan or mockup.

Earlier requirements already established **Prism Nine**, **React + Vite**, **9 × 9**, a responsive browser target, classic untimed play, three-piece trays, no player rotation, exact scoring, local progress and best score, sound/mute, pause, restart, and reduced motion. Those decisions are carried forward. The newer request labels 8 × 8 as a *proposed default*; it does not override the earlier confirmed 9 × 9 requirement.
